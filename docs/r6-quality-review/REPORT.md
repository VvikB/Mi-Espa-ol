## Содержательный результат

- Обязательное объяснение сокращено до ядра, прежний развёрнутый текст сохранён в закрытой справке. В каждом уроке выделены 5–7 продуктивных лексических опор; все прежние 10 лексических позиций доступны. Это редакторское решение о нагрузке, не доказанный экспериментом норматив A1.

- Контроль теперь содержит 6–7 пунктов по целям (всего 41), включая отдельное короткое аудио. Все 90 ограниченных ключей/вариантов просмотрены и проверены; свободные письмо/речь имеют рубрики, а не фиктивный автоматический ключ.
- Верный грамматический контроль больше не скрывает ошибку понимания. Показ транскрипта и подсказка не дают независимого успеха. 35 из 36 исходных выборов имели правильную позицию 0; новые сеансы перемешивают копии вариантов, сохраняя источник и ключ.

- Старый незавершённый сеанс, черновики, результаты и неизвестные поля сохраняются. Результат прежней редакции не получает автоматически зачёт по обновлённой модели; прежняя оценка сохраняется при новом прохождении.

## Воспроизведение

Из корня: python tools/verify_r6_review.py; python -m unittest tests/test_catalog.py -v; node tools/test_storage_r6_review.cjs. Новый прогон создаёт новую папку verification-… и не заменяет прежние отчёты. Затем python tools/package_r6_review.py --verification-dir ПУТЬ_УСПЕШНОГО_ПРОГОНА. Для одних правок документации эти тесты повторять не нужно. Для исходного R6 используйте сохранённый тег/коммит, а не текущие изменённые исходники.

Для текущего подтверждённого состояния: make r6-reviewed-package. Для нового прогона с иным путём: make r6-reviewed-package VERIFY_DIR=audit/r6-quality-review/verification-…. Сборка остановится, если отчёты не относятся к её SHA.
