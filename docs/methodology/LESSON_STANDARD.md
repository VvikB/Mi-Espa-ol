# Постоянная модель урока Mi Español, v1.0

Основание — методическая модель, переданная пользователем для R6, и MASTER SPECIFICATION v3.0, APP-03. Модель развивает существующее приложение; следующие уровни A2–B2 не отменяются. Образец A1-01 сначала проходит внутреннюю проверку, затем по этой архитектуре создаются другие уроки. Независимая содержательная проверка и внешняя экспертиза ELE отдельны от программного QA.

| Компонент | Обязательное содержание | Проверяемый результат |
|---|---|---|
| 1. CEFR и цель | Конкретное can-do, условия и пределы | Можно назвать бытовую задачу, а не только тему грамматики |
| 2. Предпосылки | Усвоенные конструкции и формулы | Новая грамматика не требуется без объяснения; опережающие выражения маркируются готовыми формулами |
| 3. Ситуация | Участники, место, мотив общения | Все основные задания помогают решить эту задачу |
| 4. Объяснение | Форма, значение, употребление, исключение и русский контраст | Не сводится к списку окончаний или ложной универсализации |
| 5. Первичный материал | Stable ID таблицы и страница/хэш изображения | Ссылка открывает правильный источник; дополнительное объяснение не выдается за дословный оригинал |
| 6. Лексика | Сочетания, перевод, заметка, ID существующей карточки | Контекст и SRS используют общую базу, без новых числовых индексов старых слов |
| 7. Диалог | Оригинальный связный обмен репликами, роли, опциональный перевод | Есть коммуникативная цель и естественная реакция |
| 8. Чтение | Оригинальный связный текст и вопросы по информации | Ответ выводится из текста, не из знаний о мире |
| 9. Аудирование | Отдельный текст/сценарий, первоначально скрытый, TTS с честной маркировкой | Ответ после завершения воспроизведения; показ текста переводит результат в чтение |
| 10. Распознавание | Выбор формы/смысла среди проверенных дистракторов | Единственный правильный вариант в заданных условиях |
| 11. Ввод/трансформация | Ограничение задачи и варианты ответа | Проверяются акценты и ñ; пунктуация/регистр нормализуются явно |
| 12. Перенос | Изменение участника, места, количества или ситуации | Не только повтор реплики диалога; условия сужают ключ до корректного набора |
| 13. Письмо | Собственная короткая продукция и конкретная рубрика | Текст сохраняется, автоматической оценки грамматики нет |
| 14. Речь | Устная задача, личные детали, честная рубрика | Самооценка помечена; приложение не утверждает, что услышало/проверило произношение |
| 15. Контроль | Не менее трёх закрытых/ограниченных задач, без кнопки подсказки | Отдельно от завершения цикла; ошибка не превращается в успешный контроль |
| 16. Ошибки | Конкретное неверное решение и объяснение причины | Обратная связь помогает исправиться, не только показывает красный цвет |
| 17. Повторение | Начальный график 1/3/7/14/30 дней, после ошибки повтор раньше | Сохраняется в том же прогрессе Journey; карточки используют существующий SRS |
| 18. Связность | Состояние шага, черновик, результаты, следующий урок | После закрытия можно продолжить; несуществующий следующий урок не выдается за готовый |

Объём — не самоцель: для каждого урока нужны собственные тексты, ситуации, перенос и критерии. Лексика может повторяться как интервальное закрепление, но механическое копирование сценария не заменяет развитие навыка. Первая учебная задача не обязана разбирать всю грамматику каждой готовой фразы.

Данные: Lesson и каждый Explanation/Lexicon/Dialogue/Reading/Listening/Task имеют постоянный ID, A1, тему/цель, происхождение NEWLY_AUTHORED_R6_NOT_HISTORICAL, соотнесение с PCIC/CEFR, первичные материалы и статус проверки. Точное соотнесение с официальными разделами пока предварительно: веб-доступ заблокирован, полных локальных документов нет. Ключи и допустимые варианты обязательны для оцениваемых задач. Свободная продукция имеет рубрику вместо ложного единственного ключа.

Технически: канонические типы заданий и один state.miJourney3, существующие события/backup/next/append; study-экран не начисляет навык. Дополнительный учебный интерфейс не создаёт второго localStorage или несовместимого журнала. Урок можно проходить частями; ориентировочная полная длительность не считается гарантией результата. Существующий технический маршрут 10/20/30 минут сохраняется, но не подменяет полный урок.

QA разделён: (1) языковая вычитка помощником с замечаниями; (2) проектная методическая проверка цели/последовательности/разнообразия; (3) код, данные, мобильный Chromium, TTS-диспетчеризация и миграция; (4) физический iPhone/Safari пользователем. Независимая содержательная проверка сопровождающим методистом и профессиональная ELE-экспертиза имеют собственные статусы и не заменяются автотестами.
