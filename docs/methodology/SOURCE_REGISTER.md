Для четырёх обзоров точные ссылки не выдумываются. Их восстановление и проверка остаются задачей реестра. Домашние страницы издателей/школ не считаются прочитанными статьями.

Приоритет: SPEC и решения пользователя → подтверждённые личные материалы → проверяемые языковые нормы → проектная методическая модель. Наличие файла, редакторская проверка помощником, независимая экспертиза ELE и пользовательская приёмка — разные состояния. Отсутствующие источники не имитируются; в отчёте R6 эта часть нормативной проверки остаётся незавершённой.
