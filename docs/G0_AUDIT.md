## Область и сохранность

Аудит продолжен в существующем `/workspace/Mi-Espa-ol`, без сброса или нового worktree.
Получен STARTER ZIP: 21 файл, из них 20 перечислены как реально присутствующие в исходном манифесте;
сам манифест — отдельный 21-й файл. Все 20 совпали по размеру и SHA-256.
Дополнительный PRODUCT_VISION.txt сохранён отдельным неизменённым оригиналом.
См. `audit/files.json`, `audit/transfer-verification.json`, `audit/received-inputs.json`.

Исторический манифест перечисляет ещё три HTML, которых нет **в STARTER**. Это не означает утрату:
расширенный ALL_AVAILABLE_HTML ZIP не доставлен инструменту из-за ограничения 32 МиБ.
Его байты, состав и SHA-256 пока неизвестны. Поле `missing_requested: []` исходного манифеста не
переопределяет фактическое отсутствие этих файлов в STARTER.

Архивные DOCX, MD, отчёты и HTML не изменены. Первый коммит сохранности: `16e50e2`.
Новая разработка до уточнения приоритета сохранена в `experimental/pre-audit-draft/` и исключена
из аудита восстановленного продукта. В частности, её 12 новых миссий, интерфейс и новые ID
не считаются восстановленными историческими уроками/данными.

## Воспроизведение

В текущей среде доступны Python 3, Node 24.22.1, Playwright и `/usr/bin/chromium`.
Точная версия Playwright и Chromium записана в `audit/browser-results.json`.
Инструменты аудита не требуют npm-зависимостей и не меняют приложения/lockfiles.
Для другой машины установите Playwright версии из результата и доступный Chromium;
при отличающемся пути измените только путь тестового раннера, не исходный HTML.

```bash
cd /workspace/Mi-Espa-ol
make test                         # статический аудит + 5 проверок инструментария
python tools/requirements_registry.py
make browser                      # исходные HTML; ожидается ненулевой код при текущих дефектах
python tools/project_manifest.py
```

`make test` не исполняет исторические тесты. `make reconstruct` заново собирает исходные
байты в `.audit/reconstruction/`, не создаёт `dist/` и не выпускает приложение.
Браузерный раннер поднимает собственный сервер на случайном loopback-порту, использует
изолированные browser contexts и синтетические данные; пользовательские данные не читает.
Сетевые ограничения песочницы в текущем исполнителе потребовали разрешённого запуска
браузера/локального сервера вне песочницы; прокси и TLS-проверки не обходились.

инвентарь, сравнение данных по хэшам, результаты UI и матрица APP-01…15 / G0…6 / Q-01…20.
