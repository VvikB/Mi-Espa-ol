# Mi Español × FORGE — согласованный план повторного использования идей
Дата: 2026-11-22. **Предложение, не релиз и не изменение учебной программы.**

## Проверенная база Mi Español
- Источник: `docs/CURRENT_STATUS.md` и `docs/NEXT_ACTIONS.md` ветки `r6-a1-lessons`.
- Исправленный R6 Reviewed ещё требует пользовательской проверки на устройстве.
- Шесть уроков A1; не заявлять полный A1–B2. Сохранены 483 словарные записи, 73 таблицы и 858 прежних ID согласно отчёту R6; не изменять эти объекты данным предложением.
- Действующий механизм backup/import JSON нельзя заменять без теста миграции и восстановления.

## Разделение задач
**FORGE**: независимые привычки и цели, несколько языков обучения, архив, фактические измерения, персональные маршруты 30/100/365 дней, агрегированная статистика, PDF/CSV/JSON.
**Mi Español**: собственный учебный контент, уроки A1–B2 по утверждённым материалам, грамматика, интерактивные листы, словарь с произношением, интервальные повторения, диагностика знаний.

## Что можно повторно использовать
1. **Измерение факта**: план 10 слов, сделано 5 или 30; сохраняется числовой факт, затем считается процент. Минуты, новые/повторённые слова, ошибки и самостоятельные ответы — различные метрики.
2. **Версии целей**: изменения плана не пересчитывают задним числом старые достижения. Схема данных нуждается в миграции и тесте старого backup.
3. **Календарь и статус**: не записано != не выполнено. Учесть пропуски, паузы, часы, локальную дату, переходы между месяцами.
4. **Аналитика**: график времени занятий, новых слов и повторений, тенденции ошибок по темам, освоение по урокам; отдельная методическая оценка знания, не только привычки.
5. **Экспорт**: формат JSON с версией и проверкой; отдельный печатный PDF и CSV без раскрытия приватных заметок по умолчанию.
6. **Адаптация**: учебное содержание не удаляется и не пропускается молча; система предлагает нагрузку с учётом результатов.

## Технологическое решение
- Не переписывать текущую HTML/JS-версию до принятия R6 Reviewed и воспроизводимого аудита.
- FORGE на React Native/Expo; нельзя переносить React Native экраны напрямую в HTML, не адаптировав интерфейс.
- Выделять только небольшие чистые алгоритмы без зависимостей от Expo/DOM/SQLite, с независимыми тестами и одинаковыми контрольными примерами.
- Рассмотреть отдельный React Native прототип Mi Español только после доказательства паритета учебных таблиц, зума/поворота изображений, озвучки, карточек, офлайн-работы и корректного импорта предыдущего прогресса.
- Не интегрировать данные приложений в реальном времени до формального определения согласия пользователя, модели авторизации и версии данных.

## Авторские права
- FORGE явно упоминает Kadō / Loop Habit Tracker как источники идей для рейтинга. Любое фактическое копирование кода требует инвентаризации исходных файлов, лицензий и уведомлений; не считать упоминание алгоритма доказательством копирования всего репозитория.
- Заимствованные образовательные материалы, иллюстрации и записи требуют самостоятельной проверки прав; не переносить внешние учебники в FORGE.
- Собственные оригинальные чистые алгоритмы можно развивать в обоих проектах с документацией происхождения.

## Критерии приёмки совместимого модуля (когда он будет реализован)
- Набор одинаковых случаев: 5/10 и 30/10 слов, 5/15 и 30/15 минут, 0.5/2 л, отсутствие записи, явный ноль, изменение цели после факта, переход месяца/года.
- Детерминированные результаты в обеих средах; без общих копий бинарных файлов и без изменения базы Mi Español.
- Проверка на iPhone: продолжение незавершённого занятия и корректный импорт backup до/после внедрения.
- Проверки речи и упражнений отдельно, без смешивания с общим рейтингом привычек.

## Следующий порядок
1. Сначала пользовательская проверка R6 Reviewed на устройстве; при необходимости точечные исправления R6.
2. Отдельный экспериментальный пакет только чистых измерительных функций (без изменения экранов или материалов).
3. Только после паритета перейти к отчётам и адаптивному расписанию.
4. Никакой новый урок или релиз R7 не объявлять завершённым из-за этого предложения.
