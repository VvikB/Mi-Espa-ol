Параллельно сверить семь личных конспектов и принять/исправить восстановленные словарные значения. После этого создавать недостающие уроки по матрице как НОВЫЕ материалы, а не восстановленные исторические. Передача большого архива, если он доступен, позволит отдельный проход поиска уникального содержания.

Сборка R4 — личная проверочная, не финальный выпуск. Проверки Chromium с имитацией голоса не подтверждают слышимость и сохранение данных в Safari/iOS; физический отчёт пользователя необходим.
