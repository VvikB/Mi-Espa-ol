# Восстановление R1: модульная база и исправление существующих функций

05.11.2026. Статус: **внутренняя рабочая копия, не финальный выпуск**.
Это новый технический пакет текущего восстановления, не объявление исторических
проходов №1–11 восстановленными. Цель остаётся MASTER SPECIFICATION v3.0 / A1–B2.

## Выполнено

- `LAST_TESTABLE` разделён на восемь исходных модулей с фиксацией исходных хэшей.
  Это сохранённый код одной ветки, а не новые уроки или реконструкция утраченного Stage11.
- `data/core.json` содержит прежние массивы; `data/images.json` — полные метаданные
  оригинальных изображений, включая исходные w/h там, где они присутствовали.
- 25 ресурсов в `assets/pages/` извлечены из data URL без перекодирования.
  MIME-тип и исходный заголовок data URL сохраняются отдельно и восстанавливаются при сборке;
  расширение файла не используется для определения типа содержимого.
- `tools/build.py` формирует только внутренний проверочный HTML в `.audit/working/`.
  Полное равенство восстановленного DB исходному проверяется перед сборкой; любое изменение
  исходных значений или байтов изображения блокирует этот пакет. Сборка детерминирована.
- Исправлен D01: динамические строки озвучки во всех шести найденных шаблонах передаются
  через экранированный `data-speech` и делегирование событий, а не исполняемый onclick.
  Проверены оба вида карточек, словарь, речевые схемы, рисунки и квизы сцен.
- Добавлен общий `AudioService` для прежних вызовов `speak`: es-ES/испанский fallback,
  единая скорость, события queued/started/ended/error/cancelled, обновление списка голосов,
  видимый статус. При отсутствии испанского голоса воспроизведение не имитируется и
  английский голос не подставляется. Системный голос и громкость iPhone требуют приёмки.
- Исправлен D02: данные ответа и ID формы отделены от JavaScript; проверка работает
  через кнопку и Enter. Ответ, открытый подсказкой, не засчитывается как самостоятельный.
  Формы сохраняют старые позиционные `gram:*` ID; новая общая миграция ещё не реализована.
- Исправлен D08: miRecall11 ставит просроченное перед новым, сохраняя оба прежних
  пространства прогресса и интервалы. Это не объединение двух очередей в одну модель.
- Исправлен обнаруженный D09 в проверенном экране настроек: цели кнопок не ниже 44×44.
  Это не полная экспертиза доступности всех SVG/экранов.

Immutable-оригиналы в `originals/` не изменились относительно первого коммита.

## Команды

```bash
python tools/build.py                 # внутренняя рабочая сборка
python -m unittest discover -s tests -v
python tools/test_restoration.py      # текущие исправления, требует Chromium
```

`tools/extract_baseline.py <пустой-каталог>` воспроизводит первоначальное извлечение
из immutable-оригинала и отказывается перезаписывать непустой каталог. Не используйте
его для замены уже исправленных src/. Обычная сборка использует сохранённые src/data/assets.
