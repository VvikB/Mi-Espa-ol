# Mi Español — восстановительный аудит G0

Статус: доступный код проинвентаризирован и проверен; полное историческое восстановление не подтверждено. Финального выпуска нет.

Пользователь подтвердил отсутствие остальных исходников. Три повторно присланных файла совпали побайтово с сохранёнными. Рабочей базой дальнейшего восстановления выбран LAST_TESTABLE; ожидание остальных HTML не блокирует исправление известных дефектов. См. актуальное уточнение в docs/G0_AUDIT.md.

- `originals/starter/` — точная распаковка полученного STARTER ZIP, включая два HTML,
  первичные DOCX/MD, исторические отчёты и исходный манифест.
- `originals/PRODUCT_VISION.txt` — неизменённый дополнительный текст пользователя.
- `experimental/pre-audit-draft/` — сохранённая новая разработка до уточнения G0;
  не восстановленные функции и не основание приёмки.
- `tools/`, `tests/` — воспроизводимые средства аудита и проверок.
- `audit/` — машинные доказательства, реестр и результаты.
- `docs/` — актуальные выводы, матрица требований и план восстановления.

Расширенный ALL_AVAILABLE_HTML ZIP пока не передан инструменту из-за лимита 32 МиБ.
Это ограничение доставки, а не доказательство утраты файлов. Оригинальные Stage10/11
не найдены **среди доступных байтов**, их отсутствие во всех источниках не установлено.

Запуск проверок и точная область покрытия описаны в docs/G0_AUDIT.md.

## Текущее восстановление R1

Создана отдельная модульная рабочая копия в `src/`, `data/`, `assets/`. Исправлены динамические обработчики аудио и таблиц, приоритет активного вспоминания и проверенные минимальные размеры кнопок. Это не финальный выпуск: [отчёт R1](docs/RESTORATION_R1.md).

`make internal` собирает только `.audit/working/Mi_Espanol_R1_INTERNAL.html`; `make repair-test` выполняет целевые браузерные проверки. Исходный аудит и его FAIL сохранены отдельно.
