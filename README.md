# Mi Español — личная проверочная версия R3

**[Скачать ZIP R3](https://github.com/VvikB/Mi-Espa-ol/raw/refs/heads/main/downloads/Mi_Espanol_Pilot_R3.zip)**

На iPhone 13 Pro Max пользователь подтвердил запуск R2 и звук словаря. R3 исправляет
озвучку схем и добавляет формы, примеры, тренировку ответа и сохраняемые занятия.
Новая слышимость R3 на устройстве ещё требует проверки.

## Что попробовать

1. Сохранить прогресс из R2 через Прогресс → Экспорт JSON.
2. Скачать и распаковать новый ZIP R3, открыть HTML привычным работающим способом.
3. Библиотека → Мои речевые схемы → TENER: всю схему, одну форму и два примера.
4. Сегодня → неделя 1 → 10 минут → Начать занятие.
5. При переносе прогресса импортировать сохранённый JSON в Прогрессе.

## Что изменилось

- Все восемь схем показывают формы, отдельно озвучиваются 45 строк и 26 примеров.
- Доступны 14 заданий, ранее уже хранившихся внутри схем.
- Есть ID материалов и явная карта 12 недель / 84 технических дневных планов.
- Занятия 10/20/30 минут: ответы, чтение/слушание, письмо, устная самопроверка.
- Позиция и черновик сохраняются; backup включает незавершённое занятие.
- Подсказка и просмотр не считаются самостоятельным успехом; текстовый fallback — чтение.
- Отсутствующие материалы отмечены. Это ещё не полный принятый курс A1–B2.

## Исходники и воспроизведение

originals/ — неизменённые вложения; src/data/assets — рабочая копия; tools/tests — сборка
и проверки; audit — доказательства; pilot/downloads — личные проверочные файлы.
Нужно Python 3, Node.js, Playwright/Chromium; версия Playwright — requirements-audit.txt.

    make test
    make internal
    make journey-test
    make backup-test
    make repair-test
    python tools/package_pilot.py

Внутренний HTML: .audit/working/Mi_Espanol_R3_INTERNAL.html. Пакетирование допускает только
артефакт, совпадающий с успешными браузерными отчётами. Это не финальный выпуск.
Стабильные ID каталога не переназначаются автоматически; исходная база и байты изображений
проверяются сборкой. Предыдущие версии R1/R2 и оригиналы сохранены.

Каждый законченный проверенный пакет отправляется в main с проверкой удалённого SHA.
Сроки — цели активной работы в чате; фоновой работы между сообщениями нет.
