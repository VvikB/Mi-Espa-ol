## Структура

- originals/ — неизменённые предоставленные материалы.
- src/, data/, assets/ — модульная рабочая копия.
- tools/, tests/ — сборка и воспроизводимые проверки.
- audit/ — хэши, инвентари, результаты и снимки.
- docs/ — план, текущий статус и отчёты.
- experimental/pre-audit-draft/ — сохранённая ранняя новая разработка, исключённая из восстановленного продукта.

## Проверки и внутренняя сборка

Нужны Python 3, Node.js и для браузерных проверок Playwright/Chromium.
Версия Playwright закреплена в requirements-audit.txt.

    make test
    make internal
    make backup-test
    make repair-test

make internal создаёт только .audit/working/Mi_Espanol_R2_INTERNAL.html.
Это технический артефакт для проверок, не финальный выпуск.
Сохранённые результаты текущего пакета — audit/restoration-r2/.
Физический Safari/iPhone, слышимость звука и долговременное хранение ещё не приняты.

## Сохранение работы

Каждый завершённый проверенный пакет: Git commit → push в main → проверка удалённого SHA.
После сессии пользователь получает короткий отчёт с конкретными ссылками.
Локальное сохранение отдельно обозначается как локальное. Git bundle — дополнительная резервная копия.
Без force push и перезаписи чужой истории. При незавершённой работе её статус и местоположение
указываются явно. Подробный порядок — в совместном плане.
