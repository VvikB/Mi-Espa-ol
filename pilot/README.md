# Пробная личная сборка R2

Mi_Espanol_Pilot_R2.html — побайтовая копия проверенного внутреннего HTML, собранного из текущих модулей. Новые уроки или новый интерфейс в эту копию не добавлены. Это не финальный выпуск по всему MASTER SPECIFICATION.

## Короткая проверка на iPhone 13 Pro Max

1. Скачайте HTML и попробуйте открыть его на телефоне.
2. Нажмите «Словарь», затем «Библиотека». Экран должен действительно переключаться.
3. Нажмите озвучку одного слова. Физическая слышимость ещё не проверена.
4. Если доступен интерактивный запуск, сохраните один ответ и проверьте его после повторного открытия. Перед длительным использованием экспортируйте копию прогресса.

Если файл показан только как предпросмотр и кнопки не действуют, интерактивный запуск не состоялся. Сообщите, как файл открывался и какая версия iOS установлена. Не считайте такой просмотр подтверждением работы Safari. Способ автономного запуска нужно будет подобрать отдельно, без молчаливой смены формата проекта.

Существующие известные ошибки связей недель/источников не исправлены этим копированием; до R3 выбирайте конкретные таблицы и страницы напрямую. Долговременное хранение, автономный запуск и системный голос на устройстве не приняты.

Контрольная сумма и привязка к проверкам — pilot/manifest.json. Учебные данные и изображения совпадают с исходной базой. Результаты для этой сборки: audit/restoration-r2/.
