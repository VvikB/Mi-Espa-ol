Mi Español — пробная личная сборка R2

В архиве лежит HTML с уже сохранёнными материалами и техническими исправлениями R2.
Это не финальный выпуск по всему ТЗ. Новые уроки в ZIP не добавлены.

Скачивание:
1. Используйте GitHub через Safari, если загрузка из чата не работает.
2. Для ZIP на странице GitHub используйте Download raw file / Скачать.
3. В приложении «Файлы» нажмите ZIP, чтобы распаковать его.
4. Попробуйте открыть Mi_Espanol_Pilot_R2.html.

Короткая проверка:
- Нажатие «Словарь» меняет экран?
- Нажатие «Библиотека» меняет экран?
- Нажатие озвучки воспроизводит испанское слово?

Если показывается только неподвижный предпросмотр, это ещё не интерактивный запуск.
Сообщите, где файл открывался и какая версия iOS установлена.
Способ локального интерактивного запуска на iPhone 13 Pro Max ещё не проверен.
Не повторяйте много раз один и тот же неработающий способ открытия.

До подтверждения запуска и сохранения на вашем устройстве регулярно сохраняйте
резервную копию после доступных занятий. Сведения о готовности: docs/CURRENT_STATUS.md.
